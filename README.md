# NbS-Suitability-Mapping
Python workflow for Nature-Based Solutions (NbS) suitability mapping using geospatial datasets and machine learning algorithms. Includes raster preprocessing, pixel-wise feature extraction, Managed Aquifer Recharge (MAR) labelling, Random Forest and Gradient Boost based MAR suitability predictions.
